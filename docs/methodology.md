# 排盤與資料核對紀錄

## 原始儲存庫缺口

初始專案僅有八字輸入、結果與節氣解讀，沒有紫微、時區或城市探索。節氣只估日期並固定於中午、日柱使用人工偏移、農曆選項未換算，metadata 硬編 UTC+8 與午夜換日。沒有測試套件或 ESLint 設定，Next.js 與鎖定檔版本不一致。此次以原 Next.js／TypeScript 元件整合，未以靜態 HTML 覆蓋。

## 指定對照案例

1987-09-23 01:05、固定 UTC+8，未啟用真太陽時，午夜／23:00 規則在此時刻不造成差異。

- 國農曆對照：丁卯年八月初一。lunar-typescript 與宿主 ICU 中國曆法在此日期相符。
- 四柱：丁卯／己酉／乙亥／丁丑。與參考包獨立的 2000-01-01 戊午日循環推算相符。
- 命宮申、身宮戌、土五局，紫微午、命宮破軍。十四主星、參考包十四輔星位置與傳統男命逆行大限逐項相符。
- 丁年生年四化：太陰祿、天同權、天機科、巨門忌；男命首限命宮 5–14 虛歲，女命順逆另測。
- 未以截圖或人為常數調整。非官方星曆認證，不能推廣為所有年份／流派均已驗證。

節氣測試以估算交節前後驗證切換邏輯及「節／中氣」差異；不將使用同套公式產生的邊界測試當作官方交節時刻的獨立證據。農曆另與 ICU 在新年及閏月日期交叉比對，亦不是官方全範圍認證。

## 寒熱與燥濕

參考版 v1 規則為文化探索，不是調候全模型或身體狀況評估：

1. 寒熱季節基分：亥子丑 −2、巳午未 +2、春秋 0。
2. 表層八字位置火−水，加藏干加權火−水；差 ≥2 加1、≤−2 減1，其餘0。
3. 藏干採單干1、雙干0.7/0.3、三干0.6/0.3/0.1。巳在原專案顯示為丙庚戊，參考權重為丙戊庚，依干名對應權重而不偷換藏干。
4. 燥濕月支：丑辰 +2、未戌 −2、子亥 +1、巳午 −1，其餘0。其餘三支濕支數減燥支數，差達 ±2 時再補 ±1。
5. −3..3，±2 才達偏性門檻。城市目標為命盤兩軸相反值，每軸最低0最高4，總分0..8。

城市先列出全部人工標籤及每一步算式；沒有基於觀測常值的正式分數。國家只計算當前目錄樣本，不 extrapolate 未收錄區域。職業筆記不參與任何分數。

## 資料來源及尚待驗證

- 算法庫：[lunar-typescript](https://github.com/6tail/lunar-typescript)、[iztro 安星說明](https://docs.iztro.com/zh_TW/learn/setup)、[IANA 時區資料](https://www.iana.org/time-zones)。固定套件版本與 lockfile 一起提交。
- 官方核對候選：[香港天文台公農曆](https://www.hko.gov.hk/tc/gts/time/conversion.htm)、[節氣定義](https://www.hko.gov.hk/tc/gts/time/24solarterms.htm)。本次嘗試讀取官方 1987／2026 PDF 回傳 HTTP 403，未匯入或冒稱已核實參考包內的 2026 官方時刻。
- 氣候標準：[WMO 氣候常值](https://wmo.int/wmo-climatological-normals)。正式資料須有同期間（例如 1991–2020）、測站識別、位置、單位、機構與可追溯網址，不能將降雨量等同相對濕度。
- 參考包中的 [BOM Brisbane 040913](https://www.bom.gov.au/climate/averages/tables/cw_040913.shtml) 是不同指標可用期間不一致的觀測統計，不能當作共同期間常值。本次該來源亦回傳 403，因此不複製未核對的溫度／雨量數字或納入正式分數。
- `ClimateNormal` 結構保留測站、期間、年均溫、年雨量、可選相對濕度、agency／url／accessedAt 及 verification。現在沒有任何 verified 常值紀錄；未來需定義資料至標籤的校準與比較期間後，才可啟用正式分數。
- 1970 年前時差、城市中心與實際出生醫院的經度差、均時差公式誤差、不同閏月及換日流派仍需使用者對照紀錄。不要把庫支持日期範圍視為每一日皆已官方驗證。
- 解讀是逐星、逐主輔組合、逐宮的文化性假設，未經個人能力／事件預測研究驗證。尚未提供完整流年／流月／流日，三方四正只提示核對，不冒充已整合。
